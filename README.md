# aviation-data-repo

The world's airports, heliports, seaplane bases and balloonports, and the US
FAA's special-use airspace and military training routes, as data for the
oceansensing.org ocean map. Whether an area or a route is active is in the
NOTAMs, not in these files.

Updated daily; the FAA's airspace and routes change with each 56-day charting
cycle.

## Sources and credits

**The FAA's airspace** comes from its Aeronautical Data Delivery Service (ADDS), a U.S. Government work whose items say *"The data provided is for public use."* Both are republished every 56 days, and each item names its cycle.
